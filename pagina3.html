Etapa 1: Levantamento de Requisitos

A base para a construção de qualquer software de alto desempenho.

1. Requisitos Funcionais (RF)

Definem o que o sistema deve fazer diretamente para os usuários finais:

  • RF01: Exibição fluida e responsiva de documentação técnica.
  • RF02: Navegação intuitiva entre as etapas do ciclo de vida de desenvolvimento.
  • RF03: Monitoramento visual do status dos serviços conteinerizados.

2. Requisitos Não-Funcionais (RNF)

Especificam como o sistema opera, focando em desempenho e infraestrutura:

Portabilidade & Isolamento
O sistema deve rodar dentro de contêineres Docker para garantir que funcione de maneira idêntica em qualquer ambiente.

Disponibilidade & Exposição Segura
Uso de proxy reverso com Nginx e tunelamento seguro via Ngrok para acesso externo sem expor portas sensíveis.
