# Laboratório Prático de Engenharia de Software

Documentação e demonstração prática cobrindo o Ciclo de Vida do Desenvolvimento de Software (SDLC), orquestração de contêineres e publicação em ambiente produtivo.

## 🛠️ Arquitetura do Sistema

- **Servidor Web / Proxy Reverso:** Nginx
- **Containerização:** Docker & Docker Compose
- **Banco de Dados Relacional:** PostgreSQL
- **Túnel de Exposição Segura:** Ngrok (com criptografia SSL/TLS)

## 📌 Etapas Cobertas no Projeto

1. **Visão de Módulos & Infraestrutura:** Configuração da stack de contêineres e portas.
2. **Etapa 1 (Levantamento de Requisitos):** Requisitos Funcionais e Não-Funcionais do ecossistema.
3. **Etapa 2 (Confiabilidade & Qualidade):** Estratégia de testes, healthchecks e integridade ACID.
4. **Etapa 3 (Deploy & Monitoramento):** Roteamento Nginx, túneis Ngrok e auto-recuperação.
5. **Etapa 4 (Ciclo de Vida & Manutenção):** Governança, atualizações e sustentação pós-deploy.
